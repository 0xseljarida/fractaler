# Fractaler

Rendering beautiful fractals (**Julia**, **Mandelbrot** and **Burning Ship**) in C [zoom, pan, color controls].

## Usage

```sh
make
./fractol M
./fractol J
./fractol J -0.8 0.156
./fractol B
```

## Libraries

- [MiniLibX](https://github.com/42paris/minilibx-linux) (Linux/X11)
